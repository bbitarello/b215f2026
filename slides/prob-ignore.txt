## Probabilities as predictions from a model {visibilty="hidden"}

::: goal
A woman wants to have a baby and wants to know the chance that her baby
will be a boy.
:::

::: incremental
-   A model is a simplified description of a (usually complex)
    mechanism.

-   Let’s try thinking of the probability of this future outcome (having
    a boy) as a prediction for this type of event based on a model.

-   Let’s create a model!
:::

## Creating/defining the model {visibilty="hidden"}

::: incremental
-   Each ovum has an X chromosome; none have Y chromosomes:
    $p[X]=1; p[Y]=0$
-   Half the sperm have one X (no Y) and half have a Y (no X)
    chromosome: $p[X]=1/2;p[Y]=1/2$
-   Only one sperm will fertilize the ovum
-   Every sperm has an equal chance of doing so
-   If winning sperm has X chromosome ($p=1/2$), joined with another X
    from ovum ($p=1$) would result in biological sex as determined by XX
    as female.
-   If winning sperm has Y chromosome ($p=1/2$), joined with an X from
    ovum ($p=1$) will result in XY (male).
-   Miscarriages are equally likely for XX or XY fetuses
:::

## Creating/defining the model {visibilty="hidden"}

:::::: columns
:::: {.column width="30%"}
::: goal
If you assume this model is true, it’s pretty easy to derive
predictions, i.e, probability of XY baby is 50%.
:::
::::

::: {.column width="70%"}
```{r gametes, fig.width=8}
gametes<-data.frame(gamete = c("egg", "sperm", "egg", "sperm"), chromosome = c("X","Y", "X", "Y"))
gametes<-data.frame(gamete = c("egg", "sperm", "egg", "sperm"), chromosome = c("X","X", "Y", "Y"), prob = c(1, 1/2, 0, 1/2))
gametes |> arrange(gamete)|> gt()
```
:::

## Same problem as before but based on data rather than a model {visibilty="hidden"}

::: goal
A woman wants to have a baby and wants to know the chance that her baby
will be a boy.
:::

::: incremental
-   According to statistics from around the world from 2011 (CIA),
    $51.7\%$ of babies born were boys

-   We don’t need to know why more boys were born

-   We don’t need to know why CIA keeps this kind of information (but it
    seems pretty “interesting”)

-   These proportions have been consistent across countries for quite a
    while
:::

## Same problem as before but based on data rather than a model {visibilty="hidden"}

::: goal
A woman wants to have a baby and wants to know the chance that her baby
will be a boy.
:::

::: incremental
-   Based on these data, the probability of having a boy is $51.7\%$ (or
    $\sim0.517$)
-   In any particular set of 1,000 pregnancies, the number of XX babies
    might not be exactly 517, but in the long run, with enough births,
    it would approach this value.
:::

## Case Study {visibilty="hidden"}

::: goal
Gelman (1998) looked at the populations of countries and the
age-adjusted, per capita incidence of kidney cancer (pretty rare cancer,
about 15 cases per 100,000 US adults).
:::

-   Results: Countries with lowest per-capita incidence -- these tended
    to be countries with small populations

-   Hypothesis: perhaps something to do with rural environments in those
    countries?

## Case Study {visibilty="hidden"}

::: goal
Random variation can have a greater effect on "averages" within small
groups than within small groups.
:::

-   Larger countries/populations: spread around the mean is lower.
-   Imagine an extreme example: a country with 1,000 people where:
    -   0 people have kidney cancer: lowest incidence possible
    -   1 person has kidney cancer: super high incidencence (100 per
        100,000)

::: notes
Logical yet unintuitive
:::
